        About these analyses

        What the labels mean

        SELF
        The citing and cited papers share at least one OpenAlex author ID.
        RECIPROCAL
        The two papers cite each other.
        ONE-WAY
        A reverse citation was not found in the verified reference data.
        OTHER / UNCONFIRMED SELF
        No shared author was established. This is not proof that no author overlaps.
        UNVERIFIED
        Required data is unavailable, so the result is not guessed.
        FETCH FAILED
        Metadata for the cited paper could not be retrieved from OpenAlex.

        How each analysis works

        Self-citation
        Author IDs of the citing paper go into a hash table with separate chaining (C99). Each cited paper's author IDs are looked up in it.
        Reciprocal citation
        The cited paper's references are stored as an adjacency list. A reverse edge to the citing paper confirms a mutual citation.
        Bibliographic coupling
        Two papers that cite at least one common reference. Reference sets are compared with a hash table, and similarity is the Jaccard index of the two sets.
        Co-citation
        Third-party papers that cite both A and B, using incoming citations from OpenAlex and the local cache. A similarity percentage is shown only when both citing lists are complete.
        Data source
        Citation data comes from OpenAlex and is cached locally in CSV files.
