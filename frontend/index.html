CiteSpect

Research Paper Citation Analysis System

Enter a paper's DOI or OpenAlex Work ID to inspect the papers it cites. CiteSpect detects Self-Citations (shared OpenAlex author IDs via a C99 Hash Table with Separate Chaining) and Reciprocal Cross-Citations (mutual citations A → B and B → A via Adjacency-List Graph traversal).

    What the categories mean

    Self-Citation (SELF)
    Two papers share at least one author.
    Reciprocal Citation (RECIPROCAL)
    Two papers cite each other.
    One-Way Citation (ONE-WAY)
    A reverse citation was not found in the verified reference data.
    Unverified (UNVERIFIED)
    Required metadata is unavailable.
    Other / Unconfirmed Self (OTHER / UNCONFIRMED SELF)
    No shared author was established.

    SELF and RECIPROCAL are independent properties, so one citation can belong to both categories.
